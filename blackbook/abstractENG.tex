This thesis documents the design, development, and evaluation of a three-tier Enterprise Resource Planning (ERP) system prototype specifically engineered to meet the operational and financial control needs of small to medium-sized enterprises (SMEs). The project addresses the prevalent issue of fragmented data and inefficient workflows in growing businesses by integrating core functions—Partner Management, Product \& Stock Control, Purchasing, and Sales—into a singular, cohesive platform.

The primary objective was to construct a robust, real-time application using a standard web stack to ensure accessibility and maintainability. This involved leveraging Structured Query Language (SQL) for the persistent and transactional data layer, housing all master and ledger information. The presentation layer utilizes HTML and CSS to deliver a responsive, user-friendly interface for all data entry and viewing requirements, connected by a server-side application layer responsible for executing all complex business logic.

The methodology focused on modeling and implementing critical ERP logic, including a weighted moving average algorithm for accurate product costing and a sophisticated Document \& Calculation Logic module designed to handle multi-level discounts and various VAT configurations. A central achievement was the successful implementation of transactional posting logic, which ensures real-time synchronization of inventory levels (Stock IN/OUT) and financial entries (Accounts Payable/Receivable) immediately upon invoice posting. Furthermore, the system incorporates essential validation checks, such as automated credit limit verification and stock availability checks before authorizing sales transactions.

The key finding of the evaluation is the validation of the system's integrated architecture, which successfully provided a unified, real-time operational dashboard and eliminated data integrity issues common in non-integrated systems. The Reporting \& Analytics module demonstrated the capability to accurately calculate profit margins and generate vital performance reports directly from the SQL-stored transactional history.

In conclusion, this project successfully delivers a comprehensive, web-based ERP solution that leverages relational database technology (SQL) to establish data integrity and provides significant benefits in process automation, inventory accuracy, and managerial decision-making capacity for scaling businesses.
